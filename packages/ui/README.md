# Design System

**Owner:** Frontend Lead (implementation) · UX Lead (specification)
**Status:** Phase 6

shadcn/ui components **copied into this repository**, not installed as a dependency.

That is deliberate: we own the source, so a WCAG defect can be fixed without waiting for an upstream
release. Owning it also means maintaining it — this package has a named owner and a per-component
accessibility test suite.

**WCAG 2.2 AA is a merge gate per component**, not a milestone.
