# Canonical painted evidence assets

These files were extracted losslessly from the canonical
`docs/brand/Witness Brand Book.pdf` using Poppler `pdfimages -all`.

- `blush-canvas.png` is the 354 x 466 Blush canvas embedded on Brand Book page 12.
- `ember-ochre-source-canvas.png` is the 560 x 726 source canvas embedded on Brand Book page 9.

They are not recoloured, filtered, regenerated or retouched. The Brand Book names Ash and Ember
canvases on page 12, but those two frames contain no embedded raster artwork. Obtain the original
approved Ash canvas before using the default Ash hero treatment described by the Brand Book.
