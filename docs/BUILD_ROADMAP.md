# BUILD_ROADMAP.md

# Witness Product Delivery Roadmap

**Version:** 2.0

**Status:** Active

**Owner:** Product Engineering

---

# Philosophy

Witness is not being built to complete technical milestones.

Witness is being built so facilitators, governments, communities and organisations can successfully run co-design sessions and preserve institutional memory.

Every release must produce a usable workflow.

Every workflow must solve a real user problem.

Working software is more valuable than complete architecture.

Architecture evolves alongside implementation.

Documentation explains software that exists.

---

# Product Principles

Every capability should improve one or more of:

- Participation
- Consent
- Trust
- Provenance
- Transparency
- Accessibility
- Institutional Memory
- Decision Intelligence

If a capability cannot improve one of these outcomes, question whether it belongs in the MVP.

---

# Release Strategy

Instead of delivering technical components, Witness delivers complete user journeys.

Every release should be deployable.

Every release should be demonstrable.

Every release should be usable.

---

# MVP Goal

A facilitator should be able to:

✓ Create an organisation

✓ Create a workspace

✓ Create a workshop

✓ Invite participants

✓ Record a session

✓ Upload files

✓ Generate AI transcript

✓ Generate AI summary

✓ Capture actions

✓ Capture decisions

✓ Search previous sessions

✓ Export results

When these twelve tasks work reliably, Witness has reached MVP.

# Engineering Workflow

Every Pull Request must deliver a complete vertical slice.

Each capability should include:

✓ Domain

✓ Database

✓ API

✓ Backend

✓ Frontend

✓ Tests

✓ Documentation

✓ Manual Verification

Avoid partial implementations.

Avoid placeholder code.

Avoid TODO-driven development.

---

# Product Workflow

After every completed capability answer:

1. What user problem did this solve?

2. Is the workflow simpler?

3. Can this be tested today?

4. Does it reduce facilitator effort?

5. Does it improve institutional memory?

6. What should be built next?

The roadmap is allowed to evolve.

User value takes precedence over roadmap order.

---

# Product Success Metrics

The MVP is successful when:

- A facilitator can run an entire co-design workshop using Witness.
- AI produces a useful transcript.
- AI extracts meaningful actions and decisions.
- Participants trust the platform.
- Previous workshops are searchable.
- Reports can be generated automatically.

Everything else is optimisation.
