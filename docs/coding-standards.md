# Coding Standards

Always

- TypeScript strict mode
- SOLID principles
- Clean Architecture
- Repository Pattern
- Dependency Injection where appropriate
- No duplicated logic
- Unit tests
- Integration tests

Never

- Hardcode secrets
- Skip validation
- Ignore TypeScript errors
- Leave TODOs
- Create dead code

Every Pull Request must

- Build successfully
- Pass lint
- Pass tests
- Include documentation
