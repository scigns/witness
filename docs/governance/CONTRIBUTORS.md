# Contributors

**Owner:** Open Source Lead
**Status:** Active

Witness exists because people build it. Everyone who contributes is credited here and in the release
notes for the release containing their work.

## What counts as a contribution

All of these. The list is ordered deliberately — code is not first, because on this project it is not
the scarcest resource.

- Public-sector operational experience that corrects our assumptions
- Indigenous data governance expertise
- Accessibility practice and assistive-technology testing
- Under-served language capability
- Archival and records-management discipline
- Adversarial security thinking and vulnerability reports
- Documentation, translation and content design
- User research and deployment reports — including reports of what failed
- Code, review, testing and infrastructure

## Attribution

- Credit is given for the work, not for the volume.
- **Sign-off is by [DCO](https://developercertificate.org/), not a CLA** — contributors retain their
  copyright. This is deliberate: a CLA assigning rights to a founding entity is a lever for future
  relicensing, and a project claiming to be public infrastructure should not hold that lever.
- If we have missed you, or credited you wrongly, please open an issue. That is a defect.
- If you would prefer not to be listed, tell us and we will remove you.

## Becoming a maintainer

Sustained quality contribution over ≥ 3 months → nomination by an existing maintainer → lazy consensus
over 7 days → merge rights in your area.

The criterion that matters most is **demonstrated judgement about what not to merge**. See
[`GOVERNANCE.md`](../../GOVERNANCE.md).
