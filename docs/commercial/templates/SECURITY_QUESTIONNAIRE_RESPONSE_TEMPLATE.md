# Security questionnaire response template

**Owner:** Security Lead
**Status:** Evidence-based response template; not certification

For every question record:

- customer question/control identifier;
- response: `IMPLEMENTED`, `PARTIALLY IMPLEMENTED`, `PLANNED`, `NOT IMPLEMENTED`,
  `OPERATOR RESPONSIBILITY`, or `REQUIRES PROFESSIONAL REVIEW`;
- concise factual answer;
- implementation evidence/link and verified version, plus either:
  - source, evidence date, reviewer, expiry/review date and implementation-vs-plan status; or
  - an evidence-room record ID that resolves to all those fields;
- deployment-specific configuration;
- limitation/residual risk;
- owner role and review date.

Cover identity, authorization, tenant isolation, encryption, secrets, logging, consent, provenance,
sovereignty/egress, dependencies, vulnerability management, incidents, backup/restore, migration,
data retention and commercial administration. Never answer from target-state architecture alone.
