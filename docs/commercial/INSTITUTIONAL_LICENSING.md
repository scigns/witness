# Institutional licensing framework

**Owner:** Commercial Lead
**Status:** Structure requiring professional review
**Review:** Before each external proposal

Institutional commercial arrangements may combine annual software licence, implementation,
training, support, hosting, dedicated infrastructure and approved integration work. Negotiated
values belong in authorised commercial systems and executed documents, never source code.

An internal modelling example may use AUD 35,000 licence + AUD 15,000 implementation + AUD 5,000
training + AUD 10,000 support = AUD 65,000 first-year value. This is illustrative unit-economics
input only, not a public or mandatory price.
