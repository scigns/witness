# Customer success and renewal

**Owner:** Institutional Customer Success Lead & Commercial Lead
**Status:** Controlled-pilot operating framework
**Review:** Per pilot stage and renewal decision

## Lifecycle

`DISCOVERY → PROPOSAL → PROCUREMENT → IMPLEMENTATION → ONBOARDING → PILOT → EVALUATION → RENEWAL DECISION`

| Stage | Required evidence |
|---|---|
| Discovery | Governance problem, sponsor, baseline and request classification |
| Proposal | Scope, package decomposition, assumptions and success measures |
| Procurement | Supplier/customer authority, approved terms, PO/invoice route |
| Implementation | Configuration, deployment, risks, recovery and go/no-go |
| Onboarding | Named roles, training, consent/data handling and rehearsal |
| Pilot | Sessions completed, incidents, support effort and governance outputs |
| Evaluation | Before/after evidence, limitations, attributable costs and sponsor feedback |
| Renewal decision | Value, risk, recurring/non-recurring economics and explicit outcome |

## Outcomes

`RENEW`, `EXPAND`, `CONTINUE CONDITIONALLY`, `PAUSE`, or `END`.

A successful paying pilot requires payment plus evidence that authorised users reconstructed
material governance history with useful completeness and provenance. Deployment, logins or invoice
payment alone are insufficient. Case studies require separate permission and redaction.
