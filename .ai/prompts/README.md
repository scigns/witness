# Development Prompts

**Owner:** CTO
**Status:** Active

Reviewed, versioned prompts for recurring development tasks.

**Not to be confused with product prompts.** Prompts used by the extraction pipeline are versioned
source code, hashed, and the hash is recorded on every extraction
([ADR-0012](../../architecture/decisions/ADR-0012-provenance-and-human-in-the-loop.md)). Those live
with the AI platform and require an evaluation delta report to change.

Prompts here are ungoverned development aids. Share useful ones.
